# Transfer to Gemini Tasks

**Director skill.** On Gemini web, go to Skills → Create → Upload. The archive is not prebuilt in this repository; from the repo root, create it with `(cd skills/anime-shorts-director && python3 -m zipfile -c ../../anime-shorts-director.zip SKILL.md GEMINI-USAGE.md references)`. Upload that ZIP. Review, create, then select @anime-shorts-director in Task mode. The ZIP is Markdown only. Google's Skills import allows one skill with up to 100 files and 100 MB and requires SKILL.md at the archive root. Gemini Apps' general attachment documentation specifies a 10-file ZIP limit and excludes audio and video. This skill ZIP fits both size and file-count limits. If a skill import is unavailable, attach SKILL.md and the relevant guide files or paste the skill text explicitly. [Skill transfer](https://support.google.com/gemini/answer/18977944?hl=en) · [General upload limits](https://support.google.com/gemini/answer/14903178?hl=en)

**Full pipeline.** Use the supplied GitHub-ready source directory as the repository root if you approve a GitHub transfer. Google documents a snapshot import up to 5,000 files and 100 MB through Gemini web → Add file → More Uploads → Import code. A private repository requires the appropriate linked GitHub account. The code import is documented as chat context, and Tasks documentation lists Upload files, Drive and Notebook. Confirm that the task can access a real checkout before running commands. If the import is context-only, the task can clone a user-authorized URL if its terminal has network and Git access, or use an authorized mounted checkout. Use the provider's access flow for private source. [GitHub import](https://support.google.com/gemini/answer/16176929?hl=en) · [Tasks help](https://support.google.com/gemini/answer/17094507?hl=en)

**Execution verification.** Google documents remote execution and downloadable file types including MP4, but does not document a general full-source ZIP intake and extraction path for this Task workflow. Use the startup prompt to test execution and file placement in the actual session. The local source directory is the distribution and no full-pipeline ZIP is designated for direct upload.

The public source repository is https://github.com/gad4523-maker/animationlab-portable. A Gemini Task needs an actual checkout (for example, `git clone https://github.com/gad4523-maker/animationlab-portable.git`), not merely a GitHub code snapshot attached as chat context. Optional third-party skill submodules can be retrieved separately with `git submodule update --init --depth 1`.
